# Tutu.ru · ручные тест-кейсы

Стенд: https://www.tutu.ru/. Браузер Chrome, окно 1920×1080, пользователь не авторизован. Для маршрута использовать Москву → Санкт-Петербург, дату через 30 дней. Не оформлять покупку, не вводить платёжные данные и не отправлять SMS.

Все кейсы подготовлены к выполнению. Статус каждого — **Не выполнен**; это не отчёт об успешном прогоне. Перед выполнением зафиксировать дату, сборку/URL, браузер или устройство. После прогона записать фактический результат и приложить доказательства; при расхождении завести дефект.
